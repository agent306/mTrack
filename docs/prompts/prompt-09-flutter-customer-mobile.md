# Prompt 09: Flutter Customer Mobile

```text
Build the customer mobile app in Flutter.

Use Stitch MCP for mobile screen/design decisions and frontend-design for UI direction. Implement the Flutter app under `mobile/`: Dashboard, Reports, Live, Playback, and Setting.

Use Google Maps on Android and Apple Maps on iOS where practical. Implement realtime tracking via the compatible Flutter WebSocket channel, mobile JWT-style auth with refresh, fleet search, map marker detail sheets, playback controls, reports, and settings.
```
